# Qela — Admin UI Kit & Layout Builder

**Qela** — это проект верстки макетов страниц и компонентов. Проект служит для разработки интерфейсов административных панелей, обеспечивая быструю сборку из компонентов и гибкую настройку стилей.

---

## ✨ Основные возможности
- **Модульность:** Генерация HTML через шаблонизатор **Nunjucks** (полное разделение на компоненты и лэйауты).
- **Продвинутый CSS:** Использование **SCSS** с архитектурой, позволяющей переопределять переменные **Bootstrap 5.3** и добавлять кастомные стили.
- **Theming:** Встроенная поддержка смены цветовых тем на уровне переменных.
- **Иконография:** Подключен и настроен иконочный шрифт **Icomoon**.
- **Custom JS:** Чистый JavaScript для реализации логики там, где недостаточно стандартных решений Bootstrap.
- **Автоматизация:** Полный цикл сборки и оптимизации на **Gulp**.

---

## 🛠 Стек технологий
- **Core:** HTML5, SCSS, JavaScript (ES6+).
- **Framework:** [Bootstrap 5.3](https://getbootstrap.com).
- **Templating:** [Nunjucks](https://mozilla.github.io).
- **Icons:** [Icomoon](https://icomoon.io).
- **Build System:** [Gulp 4+](https://gulpjs.com).

## 🚀 Установка
Убедитесь, что у вас установлен [Node.js](https://nodejs.org) (рекомендуется LTS версия).

```bash
# Клонируйте репозиторий
git clone https://github.com

# Перейдите в папку проекта
cd Qela-bootstrap

# Установите зависимости
npm install

---

## ⚙️ Команды Gulp

| Команда | Описание |
| :--- | :--- |
| `gulp` | **Режим разработки:** компиляция Nunjucks/SCSS, локальный сервер и live-reload. |
| `gulp build` | **Финальная сборка:** генерация оптимизированного проекта в папку `/Qela`. |
| `npm install` | Установка всех зависимостей проекта. |

### 4. 🎨 Особенности разработки
- **Темы:** Все основные цвета вынесены в CSS-переменные, что позволяет адаптировать админку под любой брендбук.
- **Гибкость:** Проект легко расширяется за счет компонентного подхода Nunjucks. Один раз правите компонент — он обновляется везде.
- **Оптимизация:** Gulp автоматически обрабатывает ассеты, подготавливая их к использованию в продакшене (сжатие, префиксы).
